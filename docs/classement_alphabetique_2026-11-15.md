# Classement alphabétique des fiches — 15 novembre 2026

Le tri s’applique à toutes les fiches des trois vues féminines (Train fantôme, autres portraits, résistantes locales), aux hommes avant pagination, ainsi qu’aux résultats des recherches nominatives Dachau et Ravensbrück. Le classement antérieur par réseau est supprimé de l’affichage.

Une clé explicite `nom_tri` est renseignée pour les 191 portraits. Elle reprend le nom de famille principal affiché, sans le prénom, les mentions de déportation, les surnoms et les précisions entre parenthèses. Les noms composés sont conservés. Les variantes restent intégralement dans la fiche. Exemples : Renée Bisserier sous B ; Jeanne Baptistine Porte, épouse Magnan sous P ; Wanda et Yvonne de Komornicka sous D, puis départagées par le prénom. Les particules restent comprises dans le nom affiché, de façon cohérente.

Le comparateur français ne distingue pas les majuscules des minuscules ni les accents pour le classement. À nom égal, il utilise le prénom ou l’intitulé affiché. Les fiches sources, leurs photos et leurs documents sont conservés ; seul l’ordre d’affichage change.

Validation : couverture des 191 clés, contrôles sur les quatre vues de fiches, tri avant pagination, recherches nominatives, syntaxe JavaScript et conservation des données historiques.
